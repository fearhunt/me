## Actions and research

### Changed (branch `seo/weekly-2026-11-05`)
- `vite.config.ts`: set `ssgOptions.beastiesOptions.preloadFonts = false`. Beasties was emitting about 17 `<link rel="preload" as="font">` tags per page, covering every Cyrillic, Vietnamese and latin-ext subset and one inlined base64 font, because it ignores `unicode-range`. These requests compete with the LCP portrait on mobile (LCP 2.96s) and likely feed the `render-blocking`, `network-dependency-tree` and `lcp-discovery` insights. The `@font-face` rules are still in the inlined CSS, so the browser fetches only the subsets a page uses. The build passes and `dist/index.html` now has one preload, for the stylesheet.
- Not measured: Lighthouse was not re-run here. Next week's report should confirm the LCP change and check that CLS has not risen from later font discovery (desktop CLS is already 0.046). If it has, preload just the latin Plus Jakarta Sans and Instrument Serif files by hand.

### Recommended, not changed
- **`og:image` 404s.** `index.html` and the Twitter card point to `https://firhan.id/og-image.png`, but no such file exists in `public/`. Social previews (`summary_large_image`) have no image. Add a 1200x630 PNG; this is a design asset, so I did not generate one.
- **HSTS missing in the report.** `deploy/nginx.conf` already repeats HSTS in every location (commit 293677c), so the report probably measured the old deployment. Redeploy, then confirm. I did not touch the server.
- **color-contrast (a11y 95).** The muted text colour (`--color-muted` #7e8896 on #eef2f8) is below 4.5:1 in light mode. Fixing it changes colours, so it needs your decision.
- **bf-cache.** Check which blocker Lighthouse names. Nothing in the nginx cache headers explains it (`no-cache` does not block bfcache), so it may come from a page-lifecycle listener or the theme script.
- **Person schema.** Consider adding `image` (the portrait) and more `sameAs` profiles such as GitHub. Only add them if the profiles are public and you want them linked.
- **Empty `alt` on the hero portrait.** This is correct while the figure is `aria-hidden` and decorative. Leave it.
- **/writing is "coming soon" in the sitemap.** Consider `noindex` until there is content, or accept it as a thin page.
- **Search Console.** `seo/gsc/` does not exist, so there is no query or page analysis this week. Export Performance data (queries and pages CSV) into `seo/gsc/` to enable it.

### Research (what applies here)
- Core Web Vitals thresholds are unchanged: LCP ≤ 2.5s and CLS ≤ 0.1 at p75. Chrome 151 and CrUX added soft-navigation metrics for SPAs (experimental since October 2026). This site is pre-rendered, so this only matters for client-side route changes.
- The Search Central docs updates in 2026 cover Product, VideoObject, practice-problem removal and others. None applies to a personal site, and the existing Person and WebSite JSON-LD stays valid. The 23 October 2026 crawlable-URL guidance on hyphens versus underscores is already met (`/about`, `/work`, `/writing`).
- LCP guidance still says to keep the LCP image discoverable in HTML with `fetchpriority="high"` and no lazy-loading, which the hero already does.
